Test your own model

gsw-eval is open source. Every number on this page comes from one command, and all model outputs are in the repository.

  1. Get the code and install it.
  2. Add your model to MODELS in src/gsw_eval/models.py.
  3. Run it on the test set:
gsw-eval run --model your-model --split test

Reproduce everything without a GPU or an API key:

scripts/reproduce.sh

How we measure

chrF
How many character sequences of the output match the reference, from 0 to 100. It suits a task where most errors are partial word forms.
Dialect cost
Score on Standard German input minus score on careful Swiss German. It includes each writer's own careful spelling.
Spelling cost
Score on careful Swiss German minus score on chat-style Swiss German.
Simulated chat spelling
Careful text rewritten by rules: lower case, no punctuation, short forms. Most of this changes case and punctuation, not the words. Character noise changes letters at random.
Identity
The Swiss German text copied unchanged. Every model must beat this.
